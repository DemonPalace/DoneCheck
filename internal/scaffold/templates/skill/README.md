# .skill

Instructions for AI coding agents working in this repository. Created by
`donecheck init`.

- `anti-ai-slop/SKILL.md`: engineering rules (small, real, tested, honest).
- `donecheck/SKILL.md`: the required procedure for verifying work with DoneCheck.
- `donecheck/CHECKS.md`: check types, statuses, and exit codes.
- `test-first/SKILL.md`: write a failing test before the code.
- `systematic-debugging/SKILL.md`: find the root cause before changing code.
- `self-review/SKILL.md`: review your own diff before declaring work done.

`test-first` and `systematic-debugging` are short original write-ups of ideas
popularized by the MIT-licensed [obra/superpowers](https://github.com/obra/superpowers)
skill collection, which has many more skills worth a look. No text is copied.

`AGENTS.md` at the project root points agents here. Run
`donecheck check` to verify the project against `donecheck.json`.
